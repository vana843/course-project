Лабораторная работа 2 — Умный дом
=================================

Все файлы лежат в ОДНОЙ папке. Так Visual Studio открывает проект без настройки путей.

Как открыть в Visual Studio
---------------------------
1. Распакуй архив в любую папку (например C:\Labs\lab02_flat)
2. Visual Studio → Создать проект из существующих файлов кода
3. Укажи эту папку
4. Тип проекта: Консольное приложение
5. В свойствах проекта:
   - C/C++ → Язык → Стандарт языка C++ = ISO C++17
   - Дополнительные каталоги включаемых файлов можно не трогать
     (или поставь $(ProjectDir) на всякий случай)
6. Собрать и запустить (F5)
